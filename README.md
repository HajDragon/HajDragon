##  What I've Been Up To Lately
 
- **Zorg op Afstand (Summa Experience Lab):** built a **Home Assistant dashboard** for a remote-care training setup. Nursing students act out medical scenarios in a *zorgruimte*, while a *controlekamer* monitors them and dispatches help. I piloted it with a teacher and students, processed their feedback (like modular cards), demoed it to teachers and the team, and wrote the READMEs for teachers, admins and developers.
-  **Nastiia's Gallery:** a web project with a proper workflow behind it: a CI/CD pipeline, a `feat → Dev → master` branch strategy, PR reviews and a documented version control approach.
-  **Testing in Python:** wrote a shopping cart calculator to practise systematic software testing and turn test results into concrete improvement proposals.
-  **Design process:** worked through a full design cycle (requirements, lo-fi, hi-fi, build, test) for a makeup store web project.
-  **AI-assisted dev:** exploring coding agents like opencode and Copilot to speed up prototyping without losing control of the code.
